# State Snapshot Principle

State is a snapshot at time t. It is not a single number, not a category, not a
forecast and not a recommendation.

State answers: what is happening now?

State does not answer:

- what will happen;
- what the person should do;
- whether a choice is correct;
- whether a diagnosis exists.

## Snapshot Components

A State Snapshot may include:

- Psychophysical State;
- Pressure Profile;
- Resource Profile;
- Reserve Profile;
- Trajectory State;
- Alignment State;
- Conflict Load;
- Cost Interpretation.

These components remain descriptive. They do not become authority over the
participant or over scientific interpretation.

## Time Axis

State(t) belongs to a common time axis. It must preserve timestamp and source
provenance when it is connected to questionnaires, games, sensors, prepared
data, analysis requests or model outputs.

## Forecast Boundary

State != Forecast.

A forecast is conditional and belongs to a separate layer. A state snapshot may
be used by a forecast layer, but it must not silently become a forecast.

## Governance Boundary

The model may describe pressure, resource, capacity, reserve, bottlenecks and
uncertainty. It must not prescribe behavior, priorities, medical action or
scientific conclusions.
